# HR Analytics Project: Data Cleaning and Workforce Metrics Analysis
Overview

This project focuses on cleaning and analyzing HR employee data using Python. The objective was to transform raw employee records into a reliable dataset and generate workforce metrics that support data-driven decision-making.

The project was completed as part of the Programming for Data Scientists course and demonstrates practical data preprocessing, validation, and analytical skills.

# Features
## Data Cleaning
- Removed records with missing salary values
- Standardized department names for consistency
- Removed invalid performance ratings
- Standardized hire date formats
- Validated hire dates and removed incorrect records
## Workforce Metrics
- Unique Departments Analysis
- Gender Distribution by Department
- Average Age per Department
- Employee Retention Rate
- Employee Turnover Rate
- Average Salary by Age Range
- Average Performance by Training Hours
