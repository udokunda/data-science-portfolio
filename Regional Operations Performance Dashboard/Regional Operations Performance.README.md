# Regional Operations Performance Dashboard

## Project Overview

This Power BI dashboard analyzes business performance across Southern African countries, focusing on revenue, profitability, costs, orders, and customer satisfaction. The dashboard provides interactive insights to help identify key profitability drivers and support data-driven decision-making.

## Objectives

* Evaluate revenue and profit performance across countries.
* Analyze the impact of operational costs on profitability.
* Monitor order volumes and customer satisfaction.
* Identify trends and performance patterns over time.
* Support strategic business decisions through data visualization.

## Tools Used

* Power BI
* Microsoft Excel
* DAX (Data Analysis Expressions)

## Data Preparation

The dataset was cleaned and transformed before analysis:

* Removed duplicate records.
* Handled missing values.
* Standardized date formats.
* Verified data consistency and accuracy.

## Dashboard Features

* Revenue, Profit, Cost, and Orders KPIs
* Profit Margin Analysis
* Country Performance Comparison
* Quarterly Revenue and Profit Trends
* Customer Satisfaction Analysis
* Profitability Driver Insights
* Interactive Filters and Drill-Down Functionality
