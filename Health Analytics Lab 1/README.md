# 🏥 Health Analytics Lab 1
## Overview

This project was completed as part of my Postgraduate Diploma in Data Science at the University of the Witwatersrand (Wits). The objective was to perform exploratory data analysis (EDA) on South African COVID-19 testing data and communicate insights using Python and data visualization techniques.

## Objectives
- Import and clean health-related datasets.
- Explore trends in COVID-19 testing across South African provinces.
- Create informative visualizations using Python.
- Interpret graphical results to answer health-related questions.
- Practice communicating data-driven insights.
## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
## Key Analysis

The notebook includes:

- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Weekly COVID-19 positivity rate analysis
- Provincial trend comparisons
- Data visualization and interpretation
## Example Insight

The weekly COVID-19 test positivity rate increased across all South African provinces during November 2020, peaked around late December 2020 to early January 2021, and then steadily declined through February 2021. Limpopo experienced the highest positivity rate during the second wave, while all provinces followed a similar overall trend with varying peak intensities.
