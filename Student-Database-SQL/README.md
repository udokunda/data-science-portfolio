# Student Database SQL Assignment

This project demonstrates fundamental SQL skills using MySQL Workbench.

## Topics Covered

- Creating a database table
- Inserting records
- Filtering data with WHERE
- Using BETWEEN
- Using LIKE
- AND / OR operators
- Aggregate functions (SUM, COUNT)
- GROUP BY
- NOT IN
- Date functions

## Technologies

- MySQL
- MySQL Workbench

## Files

- `student_database_queries.sql` – contains all SQL queries for the assignment.
